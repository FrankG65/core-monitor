KERN-MONITOR (Core Monitor) – Paket "Lite" (Klein) für Linux (Debian / Ubuntu)
==============================================================================

Dieses Paket enthält nur die Quelltexte (keine fertigen Programme, kein Python). Alles wird auf dem Ziel-PC frisch
aus den Quelltexten erzeugt. Benötigt wird nur, was man nutzen möchte:

  Was                           Nötig für                                    Ohne das ...
  ----------------------------  -------------------------------------------  ---------------------------------------
  1. Python 3.10+ mit venv      ALLES (Server, Seite, Python-Verfahren)      läuft nichts
  2. Internet (einmalig)        Python-Pakete per pip                        start.sh bricht mit Hinweis ab
  3. GCC (build-essential)      C, C++ (sowie Assembler, GPU)                diese sind ausgegraut
  4. NASM                       Rechenverfahren "Assembler"                  ausgegraut
  5. .NET SDK 10                Rechenverfahren "C#" und "C# SIMD"           diese zwei sind ausgegraut
  6. Rust (cargo)               Rechenverfahren "Rust" und "Rust SIMD"       diese zwei sind ausgegraut
  7. OpenCL: Header + Treiber   GPU-Rechenverfahren                          ausgegraut

Getestet unter Ubuntu 24.04 (sowie Ubuntu 22.04 / Debian 12 als älteste unterstützte Systeme), x86-64 (64-Bit-PC).
Für die SIMD-Rechenverfahren und Assembler braucht die CPU AVX2 (fast alle seit ca. 2015); sonst ausgegraut.
Die Seite erkennt CPU und Grafikkarte beim Start und zeigt unter "System", was verfügbar ist und warum nicht.

SCHRITT FÜR SCHRITT (im Terminal)
---------------------------------
1) Python und Compiler (Python Pflicht, der Rest empfohlen) - ein Befehl:
     sudo apt update
     sudo apt install python3 python3-venv build-essential nasm ocl-icd-opencl-dev clinfo
   start.sh legt eine eigene Python-Umgebung an (Ordner .venv neben start.sh) und installiert die Pakete dort
   (requirements.txt: fastapi, uvicorn, psutil, numpy, gmpy2, mpmath; dazu optional numba).
   Das Python des Systems bleibt unverändert.

2) Rust (optional, für Rust)
     sudo apt install cargo
   oder die neueste Version über https://rustup.rs
   Prüfen:  cargo --version

3) .NET SDK 10 (optional, für C#)
   - Ubuntu 24.04 und neuer:   sudo apt install dotnet-sdk-10.0
   - Ubuntu 22.04, Debian 12:  falls apt das Paket nicht findet, nach Microsofts Anleitung:
     https://learn.microsoft.com/de-de/dotnet/core/install/linux
   Prüfen:  dotnet --version          (10.x)

4) Grafikkarte (optional, für GPU): Das GPU-Programm nutzt OpenCL. Es braucht die OpenCL-Dateien aus Schritt 1
   (ocl-icd-opencl-dev) und einen OpenCL-Treiber für die Karte:
   - NVIDIA: den Hersteller-Treiber (z. B. sudo ubuntu-drivers install) - OpenCL ist enthalten.
   - AMD:    ROCm (https://rocm.docs.amd.com); alternativ  sudo apt install mesa-opencl-icd  (oft ohne double).
   - Intel:  sudo apt install intel-opencl-icd
   Prüfen:  clinfo -l     (muss die Grafikkarte auflisten)
   Ohne Treiber sind die zwei GPU-Einträge ausgegraut; alles andere funktioniert.

STARTEN
-------
1. Archiv entpacken, z. B.:     tar xzf CoreMonitor_Lite_Linux_<Datum>.tar.gz
2. Im entpackten Ordner:        ./start.sh
   Beim ersten Start werden die Python-Pakete installiert und - soweit die Werkzeuge vorhanden sind - C#, Rust,
   C, C++, Assembler und GPU übersetzt (1-3 Minuten).
3. Der Browser öffnet http://127.0.0.1:8000 - falls nicht, die Adresse selbst eingeben.
   Der Server ist nur von diesem PC aus erreichbar (127.0.0.1), nicht aus dem Netzwerk.
Beenden: Strg+C im Terminal. Anderer Port:  PORT=8001 ./start.sh

WSL (Linux unter Windows)
-------------------------
Der Kern-Monitor läuft auch in WSL (Ubuntu). http://127.0.0.1:8000 im Windows-Browser öffnen.
WSL hat keinen OpenCL-Zugriff auf die Grafikkarte - die GPU-Einträge sind dort ausgegraut.

PROBLEME?
---------
- "Python-Umgebung konnte nicht angelegt werden": sudo apt install python3-venv
- Ein Rechenverfahren ist ausgegraut: oben auf der Seite "System" aufklappen - dort steht der Grund.
- Kein Internet: auf einem Linux-PC mit Internet das Paket "Full" bauen (./export_full.sh) und dieses verwenden.
- Sprache: oben auf der Seite DE | EN umschalten (Standard = Englisch; die Wahl wird gemerkt).
  Startsprache des Servers:  KM_LANG=de ./start.sh
- Beschreibung und Projektbericht liegen in beiden Sprachen bei: README.de.md / README.md,
  Projektbericht_Parallelisierung.pdf (deutsch) / Project_Report_Core_Monitor.pdf (englisch).
- Fachbegriffe (numba, SIMD, CCX, OpenCL ...) erklärt README.de.md im Abschnitt "Glossar", mit Links.
- Ein roter Hinweis oben auf der Seite bedeutet: Der Server hat Anfragen von außen abgewiesen (z. B. von einer
  fremden Webseite). Ausgeführt wurde nichts; Einzelheiten in logs/security.log. Lizenz: LICENSE, THIRD_PARTY_NOTICES.md.
