CORE MONITOR – "Full" package
=============================

This package runs on any Windows 10/11 PC (64-bit) WITHOUT installation, WITHOUT internet and WITHOUT administrator rights.
Everything needed is included:
  - Python 3.11 (embedded version) with all packages (FastAPI, numpy, numba, gmpy2, mpmath, …)  -> folder python\
  - all 13 computation methods precompiled:
      C, C++, assembler, GPU program + precompiled shaders         -> native\bin\
      Rust                                                          -> rust\mandelbench\target\release\
      C# as a self-contained .exe (no .NET needed)                  -> csharp\bin\
  - the source code of all parts (to read and develop further)

STARTING
--------
1. Extract the ZIP, e.g. to C:\CoreMonitor (the path may contain spaces).
2. Double-click start.bat.
3. The browser opens http://127.0.0.1:8000 – if not, enter this address yourself.
   If a page is already open, it reloads itself after a restart (no extra tab).
To quit: close the black window.

The server can only be reached from this PC (127.0.0.1), not from the network.
Different port: in a command prompt run   set PORT=8001   and then start.bat.

WHAT THE PC NEEDS
-----------------
- Windows 10 or 11, 64-bit.
- For the GPU computation methods: a graphics card with Direct3D 11 and an up-to-date driver (NVIDIA, AMD or Intel).
  "GPU double" additionally needs double support in the shader. Without a suitable card these entries are greyed out.
- For the SIMD computation methods and assembler: a CPU with AVX2 (almost all since about 2015). Otherwise greyed out.
The page detects the CPU and graphics card at start-up and shows everything under "System".

NOTES
-----
- On the very first start, numba compiles its computation routine once (a few seconds).
- Antivirus software sometimes takes a little longer to check the bundled .exe files on the first start.
- Measurement results are saved in the benchmarks\ folder (CSV for Excel and JSON; the column names/keys are German).
- The package can be rebuilt on a developer PC with export_full.bat
  (produces export\CoreMonitor_Full_<date>.zip; see README.md).
- Language: switch DE | EN at the top of the page (default = English; the choice is remembered).
  Server start language: beforehand  set KM_LANG=en  or  set KM_LANG=de
- Description and project report are included in both languages: README.md / README.de.md,
  Project_Report_Core_Monitor.pdf (English) / Projektbericht_Parallelisierung.pdf (German).
- Technical terms (numba, SIMD, CCX, cardioid ...) are explained in README.md in the "Glossary" section, with links.
- A red notice at the top of the page means: the server rejected requests from outside (e.g. a foreign
  website). Nothing was executed; details in logs\security.log. License texts: LICENSE, THIRD_PARTY_NOTICES.md, licenses\.

ANTIVIRUS SOFTWARE (important, but no cause for concern)
--------------------------------------------------------
Antivirus software (e.g. Microsoft Defender, Trend Micro) and Windows SmartScreen may raise an alarm about this
program or block parts of it – this is a false positive and unfounded. These programs judge by behaviour patterns,
and Core Monitor has several that malware shows too:
  - self-compiled .exe files without a digital signature and without a "reputation" (C#, Rust, C, C++, assembler, GPU),
  - freshly extracted, unknown files from a ZIP (from the internet, by e-mail or on a USB stick),
  - many processes started at once (up to 48 Python workers) and 100 % load on all cores
    (similar to a crypto miner).
Possible symptoms:
  - "Access is denied" on the first start of a computation method, or a slow first start,
  - an .exe is moved to quarantine or deleted -> the computation method appears greyed out
    with the hint "Program missing – probably removed by antivirus software ...",
  - the warning "Windows protected your PC" (SmartScreen).
What to do:
  1. Wait a few seconds or restart start.bat – the monitor itself retries a blocked start
     for up to 10 seconds; by then the scan has usually finished.
  2. Before extracting: right-click the ZIP file -> Properties -> tick "Unblock" -> OK.
     With SmartScreen: "More info" -> "Run anyway".
  3. Check the antivirus quarantine and restore the file.
  4. Add the Core Monitor folder as an exclusion in your antivirus software – ONLY if the package comes from
     a trustworthy source (built yourself or obtained directly from the author).
  5. If you want to be sure: have individual .exe files scanned at https://www.virustotal.com,
     or use the "Lite" package and compile everything yourself from the included source code.
Please do NOT turn off your antivirus software. The Python computation methods (numba, numpy) and Pi still work
even if all .exe files are blocked.
